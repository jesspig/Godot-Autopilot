# Godot Autopilot 0.3.2

发布日期：待定。本版本是破坏性收口版本，CLI 与开发链完成一次大迁移。

## 破坏性变更

- 移除 `gda serve`、`gda api`、`gda endpoints` 与插件 REST `/api`、API token、`endpoints.api`。CLI 现在是纯客户端，只通过 IPC/MCP 连接插件。
- 移除 MCP Config 面板、客户端配置生成、技能生成按钮、端口 Apply/Pin、Copy API 与旧数据导入入口；保留日志面板。
- 移除 allow-list/`GODOT_AUTOPILOT_ALLOW`/`GODOT_AUTOPILOT_AUTH_MODE` 授权门。高风险工具改为显式 `confirm`：`destructive`、`process`、`code_execute`、`game_runtime` 无确认时返回 `confirmation_required`。
- 插件端口由插件持有并持久化；CLI 的 `--port` 仅作连接覆写，不再监听端口。
- 技能书改为 10 册 CLI-first EN/ZH 自包含版本，不含版本钉；旧 `references/` 与 REST/面板说明不再提供。

## 新增

- Trace v4：`schema_version=4`、`trace_id` 跨 CLI/插件、`dispatch_wait_ms`/`exec_ms`/`serialize_ms`、`confirm`、`args_hash`/`result_hash` 等字段；`gda trace list/show/summary/slow/failures/export`。
- `bun run gda-dev-tools <build|deploy|clean|package|package-check|test|tui>`：Bun/TS 开发链，逐步替代 Python。
- `gda install skills --zh --offline`、`gda skills list/show --zh`。
- `--confirm` 与 MCP 工具 annotations（readOnly/destructive/openWorld）。

## 迁移

| 旧用法 | 新用法 |
|---|---|
| 旧 Python 入口 `main.py build`（已删除） | `bun run gda-dev-tools build` |
| `gda serve` / `gda api` / `gda endpoints` | 删除；用 `gda call` 与 `gda tools` |
| MCP Config 面板 | `gda status --json` 的 `mcp_url` 交给 Agent 生成配置 |
| `GODOT_AUTOPILOT_ALLOW=write` | 删除；高风险工具用 `--confirm` |
| 旧 9 册技能书 | `gda install skills` / `--zh` 安装 10 册 |

## 已知限制

- 在线 CLI 下载仍依赖 GitHub/AtomGit 发布资产；AtomGit 真实上传与 macOS CI 需发布环境验证。
- Trace 的 1ms 单次开销基准尚未单独测量。
- 开发链去 Python 的最终门禁由 T-31 完成后生效。
