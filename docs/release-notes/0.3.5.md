# Godot Autopilot 0.3.5

发布日期：2026-11-25。自 0.3.4 以来，本版本以根因修复为主：统一脚本能力判定、确认协议、会话就绪握手、C# 运行时供给、场景持久化语义，以及跨平台 CI 稳定性。本文按 `.handoff/` 执行证据与 `docs/wiki/changelog/` 汇总，数值口径以 [tests.md 数值核算总表](../wiki/tests.md)为准。

## 破坏性变更

- 无工具面删除或重命名；252 个 canonical 工具与 325 个生产别名保持不变。
- `update_autoloads add` 对 C# 脚本的判定由“编辑器内可实例化”改为“运行时可挂载”：非 `[Tool]` 的 `CSharpScript` 现在可以加入 autoload；无效脚本返回结构化码 `script_class_not_found` / `base_type_not_node` / `abstract_script`。
- 确认协议归一：服务端把 `args.confirm`、call_tool 嵌套 `arguments.confirm` 与 `inputResponses`（布尔或 `action:accept`）解析为单一决策；畸形响应返回 `invalid_input_response`。外层 elicitation 只负责询问，`SpecTool` 仍是唯一执行门禁。

## 新增

- `gda:hello` 握手：编辑器为调试会话发起 hello 重试，游戏在 SceneTree 可用后回发真实 `scene_ready`；`game_ready_timeout` 与 `get_game_state(session)` 返回 `ready_diagnosis`（`extension_not_loaded` / `scene_not_ready` / `ready_lost` / `ready`）、`hello_attempts` 与 `next_action`。
- C# 运行时显式供给：`gda install plugin --with-csharp-runtime` 在 C# 项目中幂等写入 `GdaCSharpRuntime` autoload；缺桥工具返回 `missing_csharp_runtime` 与可直接执行的修复命令。
- 场景持久化可观察：场景写工具返回 `disk_persisted=false`，`save_editor_scene` 返回 `disk_persisted=true`；`editor_scene_control(play)` 返回 `autosaved` / `disk_changed` / `autosave_setting`，显式说明 Godot 默认的运行前保存。
- ready body 增加 `csharp_supported` / `csharp_bridge`，仅用于诊断，不影响 ready 门。

## 修复与加固

- 修复 Linux POSIX 绝对路径判定：路径规范化保留前导 `/`，`SchemePathContainmentTest` 三处误判消失。
- 修复 headless 单测中 Godot 单例空指针调用导致的 `ServerContextRollbackTest` 段错误；无引擎环境返回安全默认值。
- 修复文档缓存并发写入在 Windows 下 `rename` 冲突导致的 worker 退出；原子写入增加清理目标与退避重试。
- 权限测试在断言后才恢复权限，并跳过不强制目录权限的文件系统，避免 DrvFs 等环境误报。
- 技能书 EN/ZH 四篇与嵌入资产同步，wiki 错误码与字段入册。

## 迁移

| 旧用法 | 新用法 |
| --- | --- |
| 依赖 `update_autoloads` 拒绝非 Tool C# 脚本 | 现在可直接添加；由共享脚本能力模型判定 |
| 仅靠 `game_ready_timeout` 通用文案排查 | 读 `ready_diagnosis` 与 `next_action`；必要时查 `csharp_bridge` |
| 用场景探针临时挂 C# 运行时 | 用 `--with-csharp-runtime` 注册 autoload；避免 play 自动保存污染场景 |
| `--confirm` / `--input` 需要双确认 | 三种确认入口各自单独生效 |

## 已知限制

- 双平台真实 C# 项目 live e2e 未在本批次统一重跑；ready 握手状态机与既有 ready_policy 集成测试通过。
- 本机 ctest 的 `cli_unit` 在长路径下存在 IPC socket 环境限制；直接 `bun test cli/tests` 全绿，CI 三平台已绿。
- 不修改 Godot 引擎自身 autosave 默认值；临时探针需在删除后显式保存才能清理磁盘。
