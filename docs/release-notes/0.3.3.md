# Godot Autopilot 0.3.3

发布日期：2026-11-14。本版本打通「发现—观测—执行」三层，并收口安装与发布链路。

## 破坏性变更

- CLI 删除离线工具 catalog 与 `--refresh`；`gda tools list` 改为插件 live 查询，输出 `{tools, total}` 并过滤 5 个 MCP 协议工具。
- 删除 `gda tools search` / `gda tools describe`；用 `gda search` / `gda describe` 替代。
- `search_tools` 默认最多返回 20 条；需要全量枚举时显式 `limit: 0`。
- 删除 `gda cache --artifact catalog`；缓存资产只剩 `cli` / `plugin` / `skills`。
- 删除 REST 时代死代码：`api_surface`、`api_server*`、`api_auth`、`api_envelope`、`tool_execute`、`argument_validator`、`godot://endpoints` 与 `CommandQueue::execute_sync()`。

## 新增

- mcp-cpp-sdk 升至 0.3.11（OpenSSL 保持 OFF）。
- CLI 新增 `gda resources list|templates|read|watch` 与 `gda prompts list|get`；资源支持文本直出、JSON pretty、blob 摘要/`--save`。
- MCP `GODOT_AUTOPILOT_TOOL_SURFACE=full`：默认仍 7 元工具；full 暴露 459 个工具并按 100 条/页分页。
- MCP Tasks：`gda call --async` 与 `gda tasks list|get|wait|cancel|clean`。
- Progress：`--progress` 把进度写到 stderr，stdout 保持 JSON。
- MRTR：full 直接工具支持 `input_required`；TTY 提示，非 TTY 用 `--input`/`--confirm`。
- Skills 扩展：10 册技能注册为 `godot://skills/<name>/SKILL.md`，旧资源保留；2026 客户端用 `server/discover` + `skills/list|get`，旧客户端继续读资源。
- `gda status --json` 新增 `mcp` 块（protocol_version/capabilities/server_info）。
- 移除 AtomGit 发布与源码同步，GitHub Release 成为唯一发布通道；历史版本记录保留。
- 新增根 `INSTALL.md`：一键脚本、Release 手动安装、源码构建三条安装路径，面向人类与 Agent。
- 安装链路修复：Release tag 支持 `v` 前缀与无前缀两种形式，校验文件统一为 `sha256sums.txt` 并覆盖 `addons.zip`。

## 迁移

| 旧用法 | 新用法 |
|---|---|
| `gda tools search <q>` | `gda search <q>` |
| `gda tools describe <name>` | `gda describe <name>` |
| `gda tools list --refresh` | `gda tools list`（每次都走 live） |
| `gda call` 无 `--async` 的长任务 | `gda call --async` + `gda tasks wait <id>` |
| `godot://endpoints` 资源 | `gda status --json` 的 `mcp_url` 或 `gda resources list` |

## 已知限制

- full 模式面向支持宿主侧 tool search / defer loading 的本地客户端；云端 Anthropic API 无法访问仅绑环回的服务。
- Tasks 使用 `FileTaskStore`，任务按 SDK 默认 TTL 过期；过期/跨会话返回 `task not found`。
- `batch_execute` 目前只上报开始/结束两条进度，不逐 operation 上报。
- 真实编辑器的 live 冒烟（tools list/resources/tasks/full）需在 T-25 验收环境执行。
