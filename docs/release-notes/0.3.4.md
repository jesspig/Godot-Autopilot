# Godot Autopilot 0.3.4

发布日期：2026-11-23。自 0.3.3 以来，本版本以工具面收口、会话可靠性、依赖升级与代码质量治理为主线，CLI 命令面由 22 增至 23。本文按 `docs/wiki/changelog/` 中 2026-11-14 至 2026-11-23 的记录汇总，数值口径以 [tests.md 数值核算总表](../wiki/tests.md)为准。

## 破坏性变更

- 工具面压缩：catalog 459→**252**（246 个域工具 + 5 个元工具 + `system_status`），35 个域文件（新增 Image、Mesh）。被移除工具的旧名不再作为真实工具暴露，但 325 个生产别名仍可经 `call_tool` 调用至 0.6.0；同名时真实工具优先。
- 视口截图收紧：退化视口（≤8px 或零尺寸）不再静默返回 ok + 占位图，而是 2D 退化触发 3D 回退、两者皆不可用时返回 `no_scene_open` / `viewport_degenerate`。
- mcp-cpp-sdk 0.3.11 → **0.3.12**（官方声明为源码兼容 patch）：修复 Windows 上 FileTaskStore 压缩时自身追加句柄未关闭导致的任务存储中毒（`atomic write: rename failed ... The operation completed successfully.` / `task store: failed to persist task`）。GDA 业务源码零改动。

## 新增

- 分布与安装：五语 README 改为安装优先的入口卡，一键脚本统一指向 `INSTALL.md`；工程示例退场，`deploy` / `clean` 改为可重复 `--project <dir>`，`package` 支持 `--preset debug|release`。
- 技能书收敛为 **1 张入口卡 + 9 篇 references**（EN/ZH parity），MCP skills 资源 21→12，安装器新增 `--prune`。项目级新增 `gda-game-develop`（创作向）与合并后的 `gda-e2e-loop`（四阶段独立子代理闭环）。
- Game Jam 生成器 v2：题库 schema_version 2、50 条，含赛事/来源/核验字段与创意约束；新增 `jam list` / `jam index`。
- CLI 命令面 22→**23**；`code_execute` 超时回执新增 `timeout_cause`（script_error / channel_lost / unknown）与 `game_ready_timeout`。

## 修复与加固

- 任务存储路径回归集中根 `<gda_home>/.godot-autopilot/tasks/`；SDK 日志桥装配时抬到 ≥Error 并路由 LogSystem。
- CLI `stop` / `restart` 识别中毒签名并附 `--force` 风险提示；取消消息 `params.request_id` 对齐游戏桥契约；`gda:ready` 增加 `scene_ready` 并在场景入树后补发，启动窗内 create/play 报 `startup_in_progress`。
- 传输层按 `(connection_id, request_id)` 去重并改写内部 id，避免并发同号请求互相覆盖。
- 代码质量治理 ST-01～ST-05：受保护配置键写入拦截、trash 操作要求 `confirm`、反序列化限制到编辑场景子树、IPC token 契约与认证失败不降级、原子写入与路径 containment、资源事务与重命名失败回滚、元工具 elicitation / 递归深度守卫、公共 helper 复用与提示词漂移修正。

## 迁移

| 旧用法 | 新用法 |
|---|---|
| 被压缩掉的工具名 | 改用 252 个 canonical 工具名；325 个别名仍经 `call_tool` 可用至 0.6.0 |
| `examples/` 工程素材 | `gda-game-develop` / `gda-e2e-loop` 的沙盒流程 |
| `gda-e2e-testing` / `gda-e2e-analysis` | 合并为 `gda-e2e-loop` |

## 已知限制

- 0.3.4 收口批次的数值多为逐项静态核算，权威口径以 [tests.md 数值核算总表](../wiki/tests.md)为准；真实编辑器 live e2e 未在本批次统一重跑。
- `call_tool` 代理链的高风险工具已纳入 elicitation 审批，但取消路径的 live 稳定复现仍依赖具体客户端交互。
- full 工具面面向支持宿主侧 tool search / defer loading 的本地客户端；云端 API 无法访问仅绑环回的服务。
