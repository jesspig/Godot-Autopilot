# 2026-09-14 维护日志

## 2026-09-14-03

- **CI Windows 构建编码修复**：develop CI 自 2026-08-30 起连续失败的根因为 `tools/embed_skills.py` 的中文 `print`（`:222` 成功日志、`:22` `die()` 错误输出）在 GitHub Actions windows-2022 runner 的 cp1252 控制台触发 `UnicodeEncodeError`（skill 嵌入目标为构建第 1 步，失败即中止整个构建；linux/macos 因 Python 默认 UTF-8 不受影响）。修复双保险：脚本 import 后 `sys.stdout/stderr.reconfigure(encoding="utf-8")`（本地 Windows 终端同样受益）；`ci.yml`/`release.yml` job 级 env 增 `PYTHONUTF8: "1"`（经 `build.py` → cmake → `py.exe` 进程链继承）。验证：本地 `PYTHONIOENCODING=cp1252` 复现环境下成功路径（8 册 30 文件，退出码 0）与错误路径（中文错误，退出码 1）均正常，生成头与既有产物逐字节一致，workflow YAML 解析通过；`build.py` 22 处 print 全英文无同类隐患。知识库 `build.md` CI 小节与审计头同步。
