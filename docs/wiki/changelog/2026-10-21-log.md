# 2026-10-21 维护日志

## 2026/10/21 00:21

- **REST 接口面落地（`/api` 端点集）**：插件在**同一个监听端口**上新增一套 REST 风格的端点面，与既有 MCP 面（`/mcp`）并列。
  - **端点契约**（[`src/core/api_surface.cpp`](../../../src/core/api_surface.cpp)）：前缀 `/api`（常量 `GDA_API_PATH`），共 **8** 条端点——`GET /api`（服务与端点清单）、`GET /api/tools`（`query` / `category` / `tags` 过滤 + `limit` / `offset` 分页）、`GET /api/tools/<工具名>`（详情）、`POST /api/tools/<工具名>`（**请求体直接是参数对象**，无 `arguments` 外层包装）、`POST /api/batch`（`{"operations":[{"tool","args"}],"stop_on_error"}`）、`GET /api/health`（**免认证**）、`GET /api/endpoints`（端点表，与 MCP 侧资源 `godot://endpoints` 共用同一份文档）、`GET /api/openapi.json`（OpenAPI 3.0.3）。路由挂载在 [`src/core/api_server.cpp`](../../../src/core/api_server.cpp)，与 MCP 面共用同一自建 HTTP 传输层与同一把 `CommandQueue`。
  - **认证**（[`src/core/api_auth.cpp`](../../../src/core/api_auth.cpp) / [`src/core/api_token.cpp`](../../../src/core/api_token.cpp)）：除 `/api/health` 外均需 `Authorization: Bearer <令牌>`；令牌为 **32 字节随机值的十六进制**（`GDA_API_TOKEN_BYTES = 32`），来源优先环境变量 `GODOT_AUTOPILOT_API_TOKEN`、其次工程级令牌文件；比对用常量时间比较；签发后写入实例登记供 CLI 读取。
  - **错误信封归一**（[`src/core/api_envelope.cpp`](../../../src/core/api_envelope.cpp)）：工具失败统一带 `error` 与 `code`；状态码由**码**决定而非文案——401 / 400 / 404 / 403 / 503 / 504 / 500，其余归 422。**超时标记已取消且不可重试**（`main_thread_timeout` 的 `retryable` 由 true 改为 false，副作用可能仍落地）；队列不可用返回 `queue_unavailable`（`retryable=true`）。
  - 契约与已知限制见 [REST 接口面](../modules/api.md)。

## 2026/10/21 00:25

- **插件数据迁到家目录集中根**：插件数据从 `user://godot_autopilot/` 迁到**家目录集中根** `~/.godot-autopilot/`（Windows `%USERPROFILE%\.godot-autopilot\`），根下放全局配置与全局实例索引，工程级数据放 `projects/<项目名>-<路径哈希前 8 位>/`（配置、日志、轨迹、截图、实例登记按工程隔离）。
  - **根目录解析四级来源**（[`src/core/gda_home.cpp`](../../../src/core/gda_home.cpp)）：显式覆写环境变量 `GODOT_AUTOPILOT_HOME` → 平台环境变量（Windows `USERPROFILE` / POSIX `HOME`）→ 派生兜底（Windows 由 `%APPDATA%` 上溯两级；POSIX 由 `XDG_DATA_HOME` 或 `$HOME/.local/share` 上溯两级）→ 结果校验（形状 + 必须是已存在目录，首个通过者胜出，全不通过返回空串并记 Warning）。
  - **遗留兼容**：旧目录**不自动搬迁**；配置项在新路径缺键时回退读取并**注明来源**（每个键只记一次）；控制面板提供**复制式**导入（按钮 `Import Legacy Data (copy to new dir, old data kept)`），只复制不覆盖、不删除旧数据。
  - 存储布局与兼容口径见 [核心模块](../modules/core.md)「数据存储布局」。

## 2026/10/21 00:30

- **端口模型与实例登记**：端口从「单一 MCP 端口」扩为**一个端口承载两个端点**（`/mcp` 与 `/api`）。
  - **解析三级**（[`src/core/port_resolver.cpp`](../../../src/core/port_resolver.cpp)）：环境变量 → 工程级配置偏好 → 自动分配。自动分配的候选序列**先试 9527**，其后从 `20000 + (进程号 mod 10000)` 起连续递增到 29999 并回绕；**显式指定端口绑定失败时不自动更换**（由用户手动改），只有自动分配才顺延。
  - **实例登记**（[`src/core/instance_registry.cpp`](../../../src/core/instance_registry.cpp)）：插件成功绑定端口后写一条单实例记录（`instance_id` / `port` / `pid` / `project_path` / `api_token` / `endpoints` / `gda_home` / `started_at` / `version`），并**重建全局索引** `<集中根>/instances.json`。
  - **CLI 七级发现链**（[`cli/src/target.ts`](../../../cli/src/target.ts)）：`--port` ＞ `--id` ＞ 环境变量 ＞ CLI 本地注册表 ＞ 插件全局实例索引 ＞ 旧路径回退 ＞ 默认 9527，每级记录来源与链位；`gda endpoints` 一次性打印端口、来源、链位、两个端点视图与存活结果。存活校验分两级：轻量（TCP）与严格（HTTP 探活）。
  - 口径见 [端口与实例登记](../modules/ports.md)。

## 2026/10/21 00:35

- **统一执行入口与授权三档**：
  - **统一执行入口**（[`src/tools/tool_execute.cpp`](../../../src/tools/tool_execute.cpp)）：`tools::execute_tool_chain` 把「导出拦截 → 工具存在 → 参数校验 → 授权 → 派发 → 信封」六阶段固化，各段做成可替换槽位。**已知缺口**：`api_surface` 的执行器槽位在生产路径上无注册点、MCP `call_tool` 走 `execute_tool_core` 直派，故该链**尚未接入生产请求路径**——REST 面的导出拦截与参数校验当前不生效，授权门（`SpecTool::execute` 内）两套面都生效。
  - **授权三档**（[`src/tools/tool_base.hpp`](../../../src/tools/tool_base.hpp) / [`src/tools/authorization.hpp`](../../../src/tools/authorization.hpp)）：读类（`none`）**默认放行**；写类（`writes_file` / `writes_config` / `shows_alert` / `modifies_window`）**默认拒绝**；危险类（`process` / `code_execute` / `game_runtime` / `destructive`）默认拒绝且需显式开启。**写档默认拒绝是收紧方向的行为变更**——既有客户端若不做适配，调用写类工具会收到 403 `authorization_required`。能力名由四条扩为七条，新增 `destructive` 副作用类（当前唯一声明者 `delete_display_window`）。
  - 口径见 [工具注册表](../modules/tools_registry.md)「统一执行入口」与 [T0 安全边界与并发契约](../security_contract.md) §3.1 / §3.5。
