  - **错误信封归一**（[`src/core/api_envelope.cpp`](../../../src/core/api_envelope.cpp)）：工具失败统一带 `error` 与 `code`；状态码由**码**决定而非文案——401 / 400 / 404 / 403 / 503 / 504 / 500，其余归 422。**超时标记已取消且不可重试**（`main_thread_timeout` 的 `retryable` 由 true 改为 false，副作用可能仍落地）；队列不可用返回 `queue_unavailable`（`retryable=true`）。
