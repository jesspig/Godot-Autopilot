# 本项目路径约定

本文件承接 SKILL.md 的项目特定路径，按需加载；提案门槛与流程以 SKILL.md 为准。

| 用途 | 路径 |
| --- | --- |
| 知识库索引（证据读取入口） | `docs/wiki/index.md` |
| 原始痕迹层 | `docs/wiki/raw/` |
| 整理细节层 | `docs/wiki/` |
| 可执行习惯层（技能目录） | `.agents/skills/` |
| 维护日志（查重与提案状态） | `docs/wiki/maintenance-log.md` |
| 提案通过后写入位置 | `.agents/skills/<技能名>/SKILL.md` |

三层核对顺序：原始痕迹 → 整理细节 → 可执行习惯。引用一律相对路径。
