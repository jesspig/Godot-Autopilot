# 自主游戏开发与交付

围绕主题自主创作并交付一款完善、可上架的游戏。目标不是「能跑」或「能提交」，而是六维评分（Overall / Gameplay / Graphics / Audio / Innovation / Theme Interpretation）全部达到冠军水准——任一维不达标不得声称完成。美术与音频全部自主创作并落盘为资源文件，不引入来源不明素材。支持数小时长程任务：开工先写目标状态文件，按关连续推进、逐关留证与存检查点，不中途打扰用户。命令、字段与逐维判据见 `references/project-workflow.md`。

## 目标与边界

- 总目标：交付核心循环扎实、视听完整、关卡丰富、能现场运行且可直接上架的游戏，并按赛题说明准备提交作品说明；长程任务推进到 `complete` 或 `unmet`，全程留下可被离线回放消费的结构化自检证据。
- 范围：只改比赛工程本身，不改工具源码、工程模板与常驻文档。
- 范围门槛：至少 3 个可游玩关卡，关卡间有机制差异，完整通关流程不低于 5 分钟。

## 输入

- 未给主题：从题库随机抽题；给了主题：使用该主题（标识优先，再匹配唯一展示名）。
- 给了概念、项目名或范围：优先采用；给了工程路径：在该工程继续开发，按已有的赛题说明推进。
- 模板是唯一提交要求来源，不额外增加必填文档或结构。

## 执行流程（按顺序，逐步留证）

1. 抽题与读题：在仓库根抽题（可指定主题），记录主题标识与抽取记录；只读赛题说明与题库元数据，不在抽题目录中开发。一轮只抽一次题，不中途换题。
2. 概念与范围：生成 3–5 个方向，选最有钩子与创新的一个；写一句话 pitch、核心循环、主题诠释与记忆点；先跑通核心闭环再扩展内容。
3. 命名与创建：构思项目名与 slug，用脚手架命令创建工程并读取返回的工程路径；确认只含骨架文件，不手工创建最终目录。失败即停止报告。
4. 引擎准备与基线：一条命令完成构建、部署、装插件与启动引擎（默认完整编辑器，无显示才回退 headless）；用只读探针核对工程与运行状态；记录开始时间、版本、主题与抽取记录。崩溃先记录上下文再自主重启。
5. 垂直切片：先做最小可玩闭环（场景、脚本、输入、反馈、胜负/结束条件）；冷启动无阻断错误前不扩展关卡、菜单或内容量。
6. 创意迭代：每轮只做一个功能增量并实际试玩留证；只回答「这一轮让核心乐趣变强还是变弱」，变弱则回退本环。
7. 素材创作：美术与音频全部自主创作，落盘为 `res://` 资源并经导入与引用链路接入，禁止内存态直接赋值；逐项读回验证。至少一条音乐循环与关键动作音效。
8. 内容与收尾：检查失败/结束、重开、暂停与退出，难度曲线与冷启动；记录运行方式、操作与依赖。
9. 作品说明：按赛题要求准备，默认 `SUBMISSION.md`；覆盖概念、灵感、玩法机制、关卡流程、视听方向、主题诠释与操作；素材许可标注为自主生成；内容与实现一致。
10. 交付验收：按六维逐维自检并给出证据（判据表见 reference），任一维仅「可运行」或「缺失」不得声称完成；登记项目到索引；明确列出需用户亲自体验的部分。

## 工具问题处理

- 小问题换参数、换等价工具或换实现路径直接绕过；影响推进但可绕过的话记一笔在日志或交付说明里继续。
- 无法绕过且阻塞交付：停止，说明阻塞点、复现步骤与已尝试的替代路径，等待用户决定。
- 不读工具源码定位根因，不修改工具、文档、技能或测试；工具问题不写进作品说明或评审自检。

## 禁止事项

- 不在抽题目录开发、部署或打开引擎；不手工创建最终工程目录；开发过程中不再抽题或创建第二个工程。
- 不绕过工具手动编辑工程文件（骨架除外）；不修改工具源码、模板、常驻文档与版本文件。
- 不无记录重启引擎；不使用来源不明或无法说明许可的素材，不把占位或内存态素材留到交付。
- 不编造、夸大或凭印象补写试玩结果与证据。
- 不提交 git、推送、打 tag 或升版。

## 长程任务

开工先写目标状态文件（运行时产物，不预建、不提交；字段与原子写见 reference）。每关或每轮完成后：保存工程 → 由 verifier 判定 → 写检查点（含证据引用）→ 更新状态。硬指标按已保存证据判定，软指标（创意、手感、主题诠释、画面、音频）由独立子代理判定，开发者不自评。连续 2 次关卡或轮次无内容进展置为暂停并报告；仅在完结、阻塞或触达预算/用量上限时通知用户。崩溃按「先记录上下文再重启」处理。

## 结构化自检证据

每关完成或每轮交付时产出一份可被离线回放消费的结构化自检证据：只定义格式与产出时机，不在此做判定。字段与载体见 `references/project-workflow.md`；只记可观察事实与证据引用，不凭印象补写，不写未发生的状态。

## 交付清单

- 冷启动无阻断错误，核心循环可完整走通，完成度达到可上架水准；操作、结束、重开、暂停可用。
- 至少 3 关且关卡间有机制差异，完整通关不低于 5 分钟。
- 六维全部达到冠军水准并有证据，任一维不达标不得声称完成。
- 美术与音频均为自主创作、已落盘并经正常导入与引用链路接入，无占位、无来源不明素材。
- 作品说明按要求完成且与实现一致；项目已登记到索引。
- 已知缺口、未验证项与需人工试玩的部分已明确说明。
- 长程任务状态推进到 `complete` 或 `unmet`，每关/每轮结构化自检证据已保存。
- 本轮未改工具源码、文档、技能或固定模板。
