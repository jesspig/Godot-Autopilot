# 球场设计（唯一对战场地）

本文是场地几何的**唯一权威**；规则见 [mechanics.md](./mechanics.md)。坐标来自 `pong.tscn` 磁盘值，单位 px，场地逻辑尺寸 640×400。

## 场地总览

| 要素 | 节点 | 位置/尺寸 |
|---|---|---|
| 背景 | `ColorRect` | (0,0)→(640,400)，深 slate 色 |
| 中线 | `Separator`（`separator.png`） | 中心 (320,200) |
| 左拍 | `Player1`（`paddle.tscn` 实例，`left=true`，青） | (32.49,188.62) |

| 右比分 | `ScoreRight` | x 360～400，y 10～30 |
| 左胜负 | `WinnerLeft`（隐藏） | x 190～267，y 170～184 |

| 相机 | `Camera2D` | 偏移 (320,200)（未核实：是否为当前相机及缩放） |

## 边界与判定线

- 上下边：球 `direction.y` 反转线（`y<0` / `y>400`）；球拍钳制 16～384（`logic/paddle.gd:32`，高取视口高度）。
- 左右边：出界线（`x<0` 左出界判右得分；`x>640` 右出界判左得分）。
- 球碰撞：`CircleShape2D` 半径 5.11969；拍碰撞：`CapsuleShape2D` 半径 4.78568、高 23.6064（`ball.tscn` / `paddle.tscn` 原值）。

## 验收路线（单实例可走，编辑器内执行）

1. 打开 `pong.tscn`：确认背景铺满 640×400、中线居中、双拍分居左右、球近中点、比分均为 `0`、胜负标签与 Exit 隐藏。
2. 运行主场景（大厅）：截图大厅布局；Host 后保持单实例等待态，确认 `Waiting for player...`。
3. 双实例联调路线见 [../test/test-plan.md](../test/test-plan.md)：左拍把球打向右侧出界 → 左分 +1；右拍放球出右侧 → 同样左分 +1（两侧各自判定，未核实：需双实例截图确认两端比分一致）。
