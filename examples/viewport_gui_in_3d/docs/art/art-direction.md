# 美术方向与呈现要求

## 一句话方向

官方演示级写实布景 + 原生 Godot 默认主题 2D 界面：3D 侧少而素，2D 侧素而全——美术只为证明“界面在 3D 里依然清晰可用”。

## 3D 侧

- 灰调程序化天空（`ProceduralSkyMaterial` 天地平线同色）+ 全向光暖白照明，氛围中性，不抢面板的视觉焦点。
- 布景几何全为引擎原生网格（`PlaneMesh / BoxMesh`），无外部模型；立方体用浅蓝高光材质点缀，与红色 ColorRect、图标纹理形成色彩对照。
- 面板材质为无光照（`shading_mode = 0`，语义未核实）：界面亮度不受灯光影响，任何视角下文字对比度一致——截图比对时以此为基准，若发现面板随灯光变暗则为异常。

## 2D 侧

- 默认主题、缩放 2.0（源库原件值）：控件大而清晰，符合“隔着 3D 距离仍可读”的演示目标。
- 红色 ColorRect 与 `icon.webp` 图标是成像保真度的试金石：偏色、模糊、拉伸即为缺陷。
- 下拉弹窗必须与面板同风格同时成像（`gui_embed_subwindows` 的直接体现），弹窗风格断裂或缺失即为异常。

## 官方参照

- `res://screenshots/gui.png` 为官方运行截图，是构图与氛围的唯一视觉基线；新截图与之比对时允许相机相位差，但不允许布局级差异（缺控件、错位、乱码）。
