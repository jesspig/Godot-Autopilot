# 验收标准汇总

本文是验收的**总入口**：顶层验收场景 + 视觉验收要求 + 各文档分项清单索引。分项清单的详细条目在各设计文档末尾，本文不重复其内容。

## 顶层验收（必须全部通过）

> 场景 A/B/C 以 `level_01` 为例验收；三关的通过性与幂等要求相同，逐关复验时把对象 ID 换成对应关卡表中的条目。

### 场景 A：正常通关

1. 从起点出生，玩家站在地面上，HUD 水果计数为 0，相机跟随玩家。
2. 向右移动，动画在 Idle/Run/Jump/Fall 间正确切换；二段跳姿态在二段跳时出现。
3. 跳上 `platform_b` 触碰水果：计数 +1，水果消失；回到该位置不会二次计数。
4. 越过尖刺（不允许穿透判定）。
5. 触碰检查点：激活一次、HUD 提示一次、旗帜状态改变。
6. 通过双墙段：贴墙可触发墙滑/墙跳，且存在可操作的实际通过路线。
7. 触碰终点：显示胜利提示并锁定控制。

### 场景 B：死亡重生

1. 未激活检查点时触碰尖刺：死亡表现 + 输入锁定，重生回起点。
2. 激活检查点后触碰危险：重生回该检查点。
3. 重复死亡不叠加回调；水果计数不因死亡重置或重复。
4. 掉出世界下边界按死亡处理。

### 场景 C：幂等与边界

1. 多次经过检查点/终点不重复激活、不重复结算。
2. 水果只计数一次；重开后会话状态（计数、检查点）清空。
3. 胜利后接触危险不再死亡；死亡流程中再次接触危险不重入。
4. 玩家不能离开世界左右边界。

### 场景 D：菜单与解锁

1. 从工程入口启动进入主菜单，主菜单 Play/Levels/Close 三项可见可用。
2. Play 进入当前最高解锁关；Levels 进入选关界面，三张缩略图（`Levels/01-03.png`）中已解锁高亮、未解锁置灰锁定。
3. 锁定的关卡不可进入（点击无反应或有明确锁定提示，不进入 Loading）。
4. 通关 `level_01` 后结算面板显示收集率，Next 解锁 `level_02` 并可进入游玩。
5. 删除 `user://save.cfg` 后重新启动，未解锁关卡重新上锁（`unlocked` 回到 1）。

### 场景 E：敌人与箱子

1. `rock_head` 在关卡表规定的巡逻区间内来回移动；`saw` 沿轨道端点往复；`fire` 按 1.2s 熄 / 0.8s 燃周期喷发。
2. 玩家下落中踩中敌人头顶：敌人死亡并消失，玩家获得一次弹跳；侧面或下方接触敌人：玩家进入死亡流程。
3. 玩家头顶向上顶中箱子：弹出 1 个水果并计数，箱子切换为 Hit 视觉；再次顶同一箱子无事发生。
4. 敌人不触发水果计数、检查点激活与终点胜利；敌人之间互不干扰。

### 场景 F：暂停与退出

1. 游玩中按 Esc/P 进入暂停菜单，菜单 Resume/Restart/LevelSelect/MainMenu/Quit 五项可见。
2. 暂停期间玩家、敌人、喷发计时全部冻结；截图对比暂停前后世界状态一致。
3. Resume 回到与暂停前完全相同的玩法状态（位置、计数、`lives` 不变）。
4. Restart 重打本关：`lives` 不变，收集与检查点清空，回到起点。
5. LevelSelect/MainMenu 跳转到对应界面；Quit 退出游戏进程，无残留。

### 场景 G：命数与 GameOver

1. 新局 `lives=3`，HUD 常驻显示；每次死亡扣 1。
2. `lives` 归零时进入 GameOver 界面，而非重生。
3. GameOver 下 Retry 重打本关且 `lives` 回满为 3；Levels 回到选关界面。
4. 通关时 `lives+1`（上限 5）；收集齐本关全部水果通关时结算面板收集率为 100%。
