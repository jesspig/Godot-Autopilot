# 玩法机制规格

本文是玩法规则与数值的**唯一权威**。HUD/提示规格见 [ui-hud.md](./ui-hud.md)；关卡几何见 [level-design.md](./level-design.md)；动画素材见 [../art/asset-catalog.md](../art/asset-catalog.md)。

数值为设计目标值；实现者在证明原值不可行时可以调整，但必须记录"改了什么、为什么、验证证据"。

## 不变式（任何实现都必须成立）

- `死亡`、`胜利`、`已收集` 等一次性状态只能从未完成变为完成，不能被重复事件回退。
- 一次死亡流程结束前不能开启第二次死亡流程。
- 一个水果标识只能使计数增加一次。
- 一个终点触发器只能发出一次胜利事件、只结算一次。
- 重生位置 = 最近一次已激活的检查点；没有激活过则取起点。
- 一个问号箱只能触发一次出果。
- 一只敌人只能死亡一次；死亡后不再参与任何判定。
- 命数归零后必须进 GameOver，不得再重生。
- 解锁值只能单调递增（通关推进），不得被游玩过程回退；删档是唯一重置途径。
- 暂停期间不得推进 physics、计时、敌人与机关状态；输入除菜单确认外全部冻结。

## 输入语义

| 动作 | 建议键位 | 允许状态 | 行为要求 |
|---|---|---|---|
| 左移 | A、← | 可控状态 | 目标水平速度为负 |
| 右移 | D、→ | 可控状态 | 目标水平速度为正 |
| 跳跃 | 空格、W | 可控状态 | 按条件执行基础跳、二段跳或墙跳 |
| 重开 | R | 关卡内可控/死亡/胜利后 | 重载本关会话，清空收集与检查点状态，命数不变 |
| 暂停/恢复 | Esc、P | Playing/暂停菜单 | 切换暂停状态 |
| 菜单确认 | 回车、空格 | 任意菜单 | 激活当前聚焦按钮 |

- 键位是**建议**，实现者可替换，但必须至少支持键盘可玩；重开与暂停动作必须存在。
- 跳跃必须以"按键按下的瞬间"计数，不能因按住而连续触发二段跳。
- 不添加手柄、触屏、攻击、冲刺到本版。

## 坐标与视图

| 参数 | 目标值 | 单位 | 用途 |
|---|---:|---|---|
| 网格边长 | 16 | px | 地形与关卡坐标基准 |
| 设计视口 | 320 × 180 | px | 相机应覆盖的世界范围 |
| 玩家视觉尺寸 | 32 × 32 | px | 来自素材事实 |
| 玩家碰撞体 | 20 × 28 | px | 水平居中、底部与视觉脚底对齐 |

**像素呈现**：画面按像素艺术呈现——素材以原始像素尺寸显示，屏幕放大应为整数倍（例如 4× 对应 1280×720），避免非整数缩放造成模糊。具体分辨率与窗口策略由实现者决定。

### 跳跃与墙面

| 参数 | 目标值 | 单位 | 说明 |
|---|---:|---|---|
| 基础跳跃初速度 | -320 | px/s | 向上为负 |
| 二段跳初速度 | -290 | px/s | 每次离地最多使用一次 |
| 墙跳水平速度 | 220 | px/s | 方向背离墙面 |
| 墙跳垂直速度 | -300 | px/s | 触发墙跳时 |
| 墙滑最大下落速度 | 80 | px/s | 贴墙且下落时 |
| 蹭墙容错时间 | 0.08 | s | 可选：离墙后的短时间仍可墙跳 |
| 跳跃输入缓冲 | 0.10 | s | 可选：提前按键、落地即触发 |
| 踩头弹跳初速度 | -260 | px/s | 踩头消灭敌人时赋予玩家 |

**派生高度参考**（供关卡设计使用，不是额外参数）：基础跳约 57px；二段跳合计约 108px；墙跳单次约再抬升 50px；踩头弹跳约 37px。

## 玩家状态与行为

图目的：说明移动、跳跃、墙面、死亡与胜利的完整状态边界。

```mermaid
stateDiagram-v2
    [*] --> Grounded: 出生
    Grounded --> Run: 有水平输入
    Grounded --> Jump: 按下跳跃
    Grounded --> Fall: 离开地面
    Run --> Grounded: 无水平输入且在地面
    Run --> Jump: 按下跳跃
    Run --> Fall: 离开地面
    Jump --> Fall: 开始下落
    Jump --> DoubleJump: 空中按跳且次数可用
    Jump --> WallSlide: 接触可滑墙面
    Fall --> Grounded: 落地
    Fall --> DoubleJump: 空中按跳且次数可用
    Fall --> WallSlide: 接触可滑墙面
    WallSlide --> WallJump: 按下跳跃
    WallSlide --> Fall: 离开墙面
    WallJump --> Fall: 冲量完成
    DoubleJump --> Fall: 冲量完成
    Fall --> Stomp: 踩头命中敌人顶部
    Stomp --> Fall: 弹跳赋予后
    Grounded --> Dead: 接触危险
    Run --> Dead: 接触危险
    Jump --> Dead: 接触危险
    Fall --> Dead: 接触危险或跌出世界
    WallSlide --> Dead: 接触危险
    Dead --> Respawn: 死亡表现结束且有命
    Dead --> GameOver: 死亡表现结束且无命
    Respawn --> Grounded: 位置重置
    Grounded --> Won: 触碰终点
    Run --> Won: 触碰终点
    Jump --> Won: 触碰终点
    Fall --> Won: 触碰终点
```

实现要求（行为级）：

- 二段跳：落地时重置为可用一次；离地后最多消耗一次；消耗后直到落地不能再用。
- 墙滑：仅在"空中 + 接触竖直墙面 + 正在下落"时生效，下落速度被限制在上表上限以内。
- 墙跳：仅在接触墙面（或蹭墙容错窗口内）时触发；水平冲量方向背离墙面；触发后短时间内不应因反复贴墙而连续触发。
- 踩头：仅在"玩家下落中（vy > 0）+ 玩家脚底高于敌人顶部容差"时成立；成立则敌人死亡、玩家 vy 置为踩头弹跳初速度、二段跳次数不恢复；否则按玩家死亡处理。
- 死亡、重生、胜利、暂停、菜单期间不读取新的移动与跳跃输入。
- 初次出生与重生走同一条位置重置路径，保证两条路径结果一致。
- 同一帧内死亡与其他事件冲突时，以"死亡/胜利状态闸门"为准：进入死亡后忽略后续收集与胜利；进入胜利后忽略后续危险。

## 动画反馈映射

动画资源见 [asset-catalog.md](../art/asset-catalog.md)；本节只规定**状态与视觉的对应关系**，具体播放速度与过渡方式由实现者决定。

| 玩家状态 | 视觉 | 选择条件 |
|---|---|---|
| 待机 | Idle | 在地面且水平速度接近零 |
| 奔跑 | Run | 有水平输入（本版可只在地面使用） |
| 上升 | Jump | 向上运动 |
| 下落 | Fall | 向下运动 |
| 二段跳 | Double Jump | 二段跳触发后播放一次 |
| 墙跳 | Wall Jump | 墙跳触发后播放一次 |
| 踩头弹跳 | Jump | 踩头成功后处于上升段 |
| 死亡 | Hit（必要时接消失特效） | 进入死亡流程后播放一次 |
| 胜利 | 消失特效或静止胜利姿态 | 终点触发后播放 |

关键判读：动画只表达状态，不决定行为；行为由玩法状态与碰撞事件决定。

## 死亡、命数与重生

- 死亡流程：锁定输入与交互 → 播放死亡表现（目标时长 0.70s）→ 扣 1 命 → 有命则回到重生位置恢复控制（从死亡到重新可控的目标总时长 0.70s 左右），无命则进 GameOver 面板。
- 整局命数：进入任意关卡时若为新开局则 lives = 3；关卡内死亡扣命；通关 +1（上限 5）；GameOver 后 Retry 本关则 lives 回满为 3。
- R 重打本关：重载本关会话，清空收集与检查点状态，命数不变。
- 重生时先完成位置重置，再恢复交互与监测，避免出生点与危险区重叠导致同帧二次死亡。
- 死亡表现与状态时序：

```mermaid
stateDiagram-v2
    [*] --> Alive
    Alive --> DeathRequested: 首个危险事件
    DeathRequested --> DeadVisual: 锁定输入与交互
    DeadVisual --> LifeCheck: 死亡表现结束
    LifeCheck --> RespawnPending: 有剩余命（扣1）
    LifeCheck --> GameOver: 无剩余命
    RespawnPending --> ResetPosition: 读取最近检查点
    ResetPosition --> SpawnVisual: 设置位置并清零速度、清理临时状态
    SpawnVisual --> Alive: 恢复控制
    Alive --> Won: 终点触发
    Won --> Unlock: 结算并推进解锁
    Unlock --> [*]
```

## 敌人行为契约

敌人只监听玩家；敌人之间、敌人与收集品/检查点/终点互不触发。

### 石怪巡逻（rock_head，可踩）

- 沿地面巡逻区间来回移动，水平速度 40px/s；到达区间端点即转向；巡逻区间与初始朝向见 [level-design.md](./level-design.md)。
- 玩家踩头成立时：石怪死亡并消失、玩家弹跳、HUD 可选一次击杀反馈；一只石怪只死亡一次。
- 玩家非踩头接触时：玩家进入死亡流程。
- 石怪不受重力参数表约束（贴地移动即可），不跳跃、不追踪。

### 轨道锯（saw，不可踩）

- 沿直线轨道在两端点间往复移动，速度 60px/s；轨道端点见 [level-design.md](./level-design.md)。
- 任何接触（包括从上方）均使玩家进入死亡流程；锯不可被消灭。
- 到达端点即折返，不得冲出端点。

### 定时火（fire，周期危险）

- 周期 2.0s：熄灭 1.2s（无害，可通过）→ 燃烧 0.8s（接触即死）→ 循环；相位偏移按关卡表（同关可错峰）。
- 燃烧视觉与熄灭视觉必须一眼可辨；判定只在燃烧段生效。

## 交互对象的行为契约

### 水果（收集品）

- 玩家接触未收集的水果时：计数 +1、该水果标记为已收集并从场景中消失、播放已存在的收集特效（可选）。
- 8 种水果分关使用（种类分布见 [level-design.md](./level-design.md)）；计数为本关会话内计数。
- 每个水果有唯一的会话内标识；计数前先检查标识集合，重复信号不能重复加一。
- 死亡重生不恢复已收集水果，避免刷计数。
- 水果消失有短暂延迟（用于播放特效）时，延迟期间不得再次计数。

### 问号箱（顶触发）

- 玩家头顶向上顶箱底时：箱子切换为 Hit 视觉、 spawn 1 个水果并立即计数 +1；每箱仅触发一次。
- 从侧面/上方接触箱子无事发生；箱子本身不可站立穿透（按实体处理或按关卡表语义）。
- 顶触发只在玩家上升段（vy < 0）且头顶接触箱底时成立。

### 尖刺与锯火（静态/周期致命陷阱）

- 静态尖刺：玩家接触即进入死亡流程；只提交死亡请求，由关卡状态决定是否接受。
- 未列入敌人三型的其他陷阱素材本版不实例化。

### 检查点

- 玩家进入未激活检查点时：记录重生位置、切换为"已激活"视觉、HUD 显示一次激活提示（提示规格见 [ui-hud.md](./ui-hud.md)）。
- 已激活的检查点再次进入不发出新的事件。
- 关卡重载/R 重打会清空会话状态；检查点不写入磁盘。

### 终点与解锁

- 玩家触碰终点触发一次：锁定输入与交互 → 播放终点目标视觉 → 显示结算面板（含本关收集率）。
- 结算时推进解锁：`unlocked = max(已存, 本关序号 + 1)`，上限 3，写入 `user://save.cfg` 的 `[progress] unlocked`；写盘失败必须在日志中暴露错误。
- 最后一关通关后显示通关完成态，不再推进。

### 存档

- 唯一可写盘数据：`user://save.cfg` → `[progress] unlocked`（int，默认 1）。
- 读档：启动与进入选关时读取；文件缺失或字段非法时按默认 1 处理并在日志中记录。
- 除解锁值外，任何会话状态（收集、检查点、命数、位置）不得写盘。

### 世界边界

- 左右边界为不可穿越的物理边界，玩家不能离开世界。
- 世界下方有死亡检测区：玩家跌出后按死亡流程处理；该区域不得与终点或地面语义重叠。

### 暂停

- Esc/P 在 Playing 与暂停菜单间切换；暂停时冻结 physics、计时、敌人与机关相位；恢复后从冻结点继续。
- 暂停菜单选项：Resume（恢复）、Restart（重打本关，命数不变）、LevelSelect（回选关）、MainMenu（回主菜单）、Quit（退出游戏）。
- 暂停/菜单期间移动与跳跃输入无效，仅菜单确认有效。

## 边界情况清单

- 同一物理帧内玩家同时接触水果与危险：以死亡状态闸门为准，死亡后不得再产生收集事件；关卡验收时应避免两者重叠放置。
- 同一物理帧内同时接触检查点与危险：检查点必须先记录激活再进入死亡；重生位置为该检查点。
- 胜利同一帧接触危险：胜利状态先锁定则忽略危险，反之亦然；必须用明确的状态闸门保证确定性。
- 踩头同一帧接触另一危险：踩头成功与死亡按触发器求值顺序以状态闸门裁决，关卡验收时应避免敌人与尖刺重叠放置。
- 玩家跌出世界下边界：按死亡处理。
- 重开关卡/R 重打：清空收集集合与检查点状态，回到起点；不伪造持久化存档。
- 命归零：不得再重生，必须进 GameOver。
- 资源缺失/导入失败：应在运行日志中暴露具体资源路径，不得静默回退到替代素材。

## 玩法验收

- [ ] 左/右输入在地面与空中均能控制角色；角色朝向与移动方向一致。
- [ ] 基础跳高度接近 57px；二段跳在基础跳之上再抬升接近 50px；二段跳每次离地只可用一次，落地恢复。
- [ ] 贴墙下落时速度被限制；墙跳触发方向背离墙面；左右墙均可触发。
- [ ] 玩家不会穿透地形，也不会因重力、速度或碰撞体异常跌出世界（除死亡边界外）。
- [ ] 接触尖刺/锯/燃火只触发一次死亡流程；死亡期间输入无效；重生回到最近检查点并扣命。
- [ ] 石怪巡逻区间正确折返；踩头消灭且玩家弹跳；侧碰致死；锯不可踩。
- [ ] 问号箱顶触发出果并计数，每箱仅一次；侧碰无事发生。
- [ ] 水果只计数一次；死亡重生不重复计数；已收集水果不再出现。
- [ ] 检查点只激活一次；重复进入不重复提示。
- [ ] 终点只触发一次胜利并结算；胜利后不再响应移动、收集与危险；解锁值正确推进并写盘。
- [ ] 命数：开局 3 命，死亡扣命，归零进 GameOver，通关加命上限 5，R 重打命数不变。
- [ ] 暂停冻结 physics 与计时；暂停菜单五项可用；恢复后状态连续。
- [ ] 重开动作可用，且正确清空会话状态（命数按规则保留）。
