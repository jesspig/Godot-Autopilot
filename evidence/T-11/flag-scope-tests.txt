===================================

状态：代码与新增测试已写入；本子代理未运行 bun test / tsc / 构建。

1. MCP 专属 flag 删除（公开 CLI 不再识别）
  --transport    删除（args.ts STRING_FLAGS / command-spec tool.call / usageText）
  --no-fallback  删除（BOOLEAN_FLAGS / usageText）
  --direct       删除（BOOLEAN_FLAGS / tool.call / usageText）
  --input        删除（STRING_FLAGS / tool.call / usageText）
  --async        删除（BOOLEAN_FLAGS / tool.call / usageText）

  通用调用统一走 gda tool call，异步统一走 gda job。

2. 兼容 alias
  --json → --format json（args.ts VALUE_ALIASES；parseArgv 与 parseCommandArgs 均归一到 formatText）
  outputFormat() 仅接受 json；trace export 的 --format 拆为 --export-format。
  FLAG_MIGRATIONS（command-spec.ts）逐条记录 from/to/reason，manifest 暴露 flag_migrations。

3. 多义 flag 拆分
  --force → --force-stop（editor.stop/restart）、--force-clear（docs.clear/cache.clear/job.clean）、
            --force-install（update.run）
  --all   → --all-projects（editor.list/project.list）、--all-buckets（docs.clear）
  --file  → --report-file（debug.report）、--skill-file（skill.show）、--input-file（monitor.report）
  --probe → --probe-level（editor.start）、--probe-port（editor.list）

4. 作用域校验
  command-spec.ts GLOBAL_SCOPE_FLAGS 限定命令树可用全局 flag；其余必须由 spec.flags 声明。
  parseCommandArgs 对非 repeatable flag 重复出现直接抛 ExitCode.Usage；
  --tag/--include 为 repeatable，收集为 string[]。
  --args-file - 在两个 parser 中均被接受（"-" 是合法值）。
