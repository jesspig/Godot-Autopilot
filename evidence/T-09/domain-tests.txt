## 三、确认矩阵（统一 --confirm，非交互缺确认不执行）

| 类别 | 命令 | 行为 |
| --- | --- | --- |
| 高危（code_execute / destructive / process / game_runtime） | script exec、script delete、resource rename、resource move、game play/start/stop/input/eval/scenario | 前置检查：缺 `--confirm` 直接抛 Usage 错误，**不发送任何原生调用**；带 `--confirm` 时在 call.start 参数中写入 `confirm=true` |
| 低危写（writes_scene/writes_file，按 GDA 安全姿态无需确认） | scene node/property/signal/save/add/open、script create/patch/attach/reload、resource set/save/import、game capture | 直接调用，不要求 `--confirm` |
| 只读 | scene tree/verify/diff/list、script list/read/compile/test、resource inspect/get/references/list/read/watch/templates/prompts、game status | 直接调用；不携带 `confirm` |

补充：`nativeToolInvoke` 仍保留服务端二次 challenge 处理 —— 若服务器返回
`needs_confirmation` 且调用方已带 `--confirm`，自动发 `call.confirm`；否则抛出
`confirmation_required` 工具失败，不切换到别名或其他工具绕过。wrapper 不复制业务逻辑。

## 四、参数与输出适配

- 简单参数用 flags；复杂 JSON 用 `--args` 或 `--args-file`（含 `--args-file -` 从 stdin 读取）。
- `--args-file` 内容必须是 JSON 对象；与 `--args` 同时出现报用法错误；
  `--value` 与 `--args-file`、`--source` 与 `--args-file` 互斥。
- 所有领域命令输出统一 envelope：`schema_version, ok, command, tool, action,
  scene_path, revision, receipt{request_id,digest,artifact_id}, result,
  task_id, error, new_errors_since_last_call`。写命令的 `scene_path/revision` 优先取工具结果，
  缺失时回退到参数的 `path/parent_path`；`receipt` 来自 GCP 请求 id 与 artifact 摘要。
- GCP params 为扁平字符串 map；对象/数组 JSON.stringify 后传入，与 C++ `GcpInvocationSink`
  把每个 param 作为字符串写入工具 arguments 的契约一致。

3. T-08 的 `tool.ts` 对 `call`/`batch` 仍拒绝；本任务在 `gda.ts` 层为 `tool.call` 加原生路由，
   `gda tool batch` 仍按 T-08 行为指向 legacy `gda batch`（不在授权文件内，未改 `tool.ts`）。
4. `nativeToolInvoke` 自行实现 GCP 帧解析与 request_id 复用，未复用 `ipc/client.ts`；
   需主代理统一 typecheck 与 fake-server 用例验证 needs_confirmation 与 call.confirm 顺序。
5. 工具参数从 flags 扁平化为字符串 map，依赖 C++ handler 接受字符串形式的 JSON（与
   `GcpInvocationSink` 现有实现一致）；真实引擎下复杂值（Vector/Array/Dictionary）需
   主代理用最小场景确认一次。
6. `scene compile` 没有独立 canonical 工具，采用 `patch_script` + `dry_run=true` 做编译检查；
   若真实 handler 要求 anchor/content 才能 dry-run，需主代理确认参数完整性。
7. T-08 遗留的 script/resource 占位工具名已改为真实 canonical 工具；其参数 schema
   未按 `gda describe` 逐项核对（本任务未连接真实编辑器），需主代理对高频命令做一次真实 smoke。
