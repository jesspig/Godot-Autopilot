# 类超级马里奥游戏 - 开发文档

## 使用说明

1. **新成员入门**: 先阅读 ONE_PAGE_DESIGN.md 了解游戏概念，再深入阅读 GAME_DESIGN_DOCUMENT.md
2. **美术资源制作**: 严格按照 ART_ASSETS.md 中的尺寸规格制作，注意文件命名规范
3. **开发参考**: 所有技术实现细节参考 TECHNICAL_DESIGN.md
4. **关卡制作**: 遵循 LEVEL_DESIGN.md 中的设计原则和模板
