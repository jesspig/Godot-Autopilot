**四角色总帧数**: 43 × 4 = **172帧**

### 1.4 角色动画状态机

```mermaid
stateDiagram-v2
    [*] --> Idle: 关卡开始
    
    Idle --> Run: 方向键输入
    Idle --> Jump: 跳跃键
    Idle --> Hit: 接触陷阱
    
    Run --> Idle: 松开方向键
    Run --> Jump: 跳跃键
    Run --> Wall Jump: 贴墙 + 跳跃
    Run --> Hit: 接触陷阱
    
    Jump --> Fall: 到达最高点
    Jump --> Double Jump: 空中跳跃键
    
    Fall --> Idle: 落地
    Fall --> Double Jump: 空中跳跃键
    Fall --> Wall Jump: 贴墙 + 跳跃
    Fall --> Hit: 接触陷阱
    
    Double Jump --> Fall: 动画播完/到达最高点
    Double Jump --> Hit: 接触陷阱
    
    Wall Jump --> Fall: 动画播完
    Wall Jump --> Run: 落地
    Wall Jump --> Hit: 接触陷阱
    
    Hit --> Idle: 动画播完 (无敌时间)
    Hit --> [*]: 死亡 (掉落/陷阱)
    
    note right of Idle
        11帧呼吸循环
        0.10s/帧
    end note
    
    note right of Run
        12帧奔跑循环
        0.08s/帧
    end note
    
    note right of Double Jump
        6帧空中旋转
        0.08s/帧
    end note
```

### 2.3 动画帧详解

#### Idle 待机 (11帧)

```mermaid

    F1[帧1 站立] --> F2[帧2 微升]
    F2 --> F3[帧3 继续升]
    F3 --> F4[帧4 最高点]
    F4 --> F5[帧5 微降]
    F5 --> F6[帧6 继续降]
    F6 --> F7[帧7 最低点]
    F7 --> F8[帧8 微升]
    F8 --> F9[帧9 继续升]
    F9 --> F10[帧10 最高点]
    F10 --> F11[帧11 回落]
```

| 6 | +1px | 微降 |
| 7 | +1px | 最低点 |
| 8 | +1px | 继续下沉 |
| 9 | 0 | 回升 |
| 10 | 0 | 回到中间 |
| 11 | -1px | 准备下一循环 |

**动画要点**: 呼吸效果通过身体上下 1-2 像素实现，面具带轻微晃动

| 6 | 左脚跟进 | 左前右后 | 直立 |
| 7 | 右脚蹬地 | 右后左前 | 前倾3px |
| 8 | 腾空瞬间 | 双脚并拢 | 前倾2px |

| 11 | 过渡帧 | 左脚前 | 前倾1px |
| 12 | 过渡帧 | 回到帧1 | 前倾2px |

**动画要点**: 完整跑步循环，身体上下浮动 2-3 像素，面具带飘动效果

| 帧号 | 动作描述 | 闪烁 |

**动画要点**: 受击后仰 + 闪烁效果，最终帧角色消失触发死亡流程

| 帧号 | 动作描述 | 方向 |

### 6.4 特效使用流程

```mermaid
sequenceDiagram
    participant G as 游戏逻辑
    participant FX as 特效播放器
    participant C as 角色精灵
    
    Note over G,C: 关卡开始
    G->>FX: 播放 Appearing (7帧)
    FX->>FX: 逐帧播放 0.7秒
    FX->>G: 特效完成回调
    G->>C: 切换角色 Idle 状态
    
    Note over G,C: 角色死亡
    G->>FX: 播放 Desappearing (7帧)
    FX->>FX: 逐帧播放 0.7秒
    FX->>G: 特效完成回调
    G->>G: 显示死亡界面/复活
```

```mermaid
        P2[优先级 2 可被打断]
        P3[优先级 3 随时切换]
        
        P1 --> P1A[Hit 受击]

        P1 --> P1C[Desappearing 消失]
        
        P2 --> P2A[Double Jump 二段跳]

    end
```

### 7.3 动画切换规则

| 当前状态 | 可切换至 | 条件 |
|---------|---------|------|
| Idle | Run | 方向键输入 |
| Idle | Jump | 跳跃键按下 |
| Idle | Hit | 接触伤害 |
| Run | Idle | 松开方向键 |
| Run | Jump | 跳跃键按下 |
| Run | Wall Jump | 贴墙 + 跳跃 |
| Jump | Fall | 垂直速度 ≤ 0 |
| Jump | Double Jump | 空中按跳跃 + 有二段跳次数 |
| Fall | Idle | 落地检测 |
| Fall | Double Jump | 空中按跳跃 |
| Fall | Wall Jump | 贴墙 + 跳跃 |
| Double Jump | Fall | 动画播完或垂直速度 ≤ 0 |
| Wall Jump | Fall | 动画播完 |
| Wall Jump | Run | 落地 |
| Hit | Idle | 动画播完 (0.7s) |

### 7.4 精灵翻转规则

|------|------|

| 蹬墙跳(左墙) | 面向右 `flip_h = false` |
| 蹬墙跳(右墙) | 面向左 `flip_h = true` |
