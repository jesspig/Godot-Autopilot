## 2. 音乐系统设计

### 2.1 音乐切换流程

```mermaid
sequenceDiagram
    participant G as 游戏事件
    participant M as 音乐管理器
    participant A as 音频播放器
    
    G->>M: 场景切换
    M->>A: 淡出当前 BGM (1秒)
    A->>A: 音量渐降至 0
    A->>M: 淡出完成
    M->>M: 加载新 BGM
    M->>A: 播放新 BGM
    M->>A: 淡入新 BGM (1秒)
    A->>A: 音量渐升至目标值
    
    Note over G,A: Boss 战切换
    G->>M: 进入 Boss 战
    M->>A: 快速淡出 (0.3秒)
    M->>A: 播放 Boss BGM
    M->>A: 快速淡入 (0.3秒)
    
    Note over G,A: 无敌状态叠加
    G->>M: 获得无敌星
    M->>M: 保存当前 BGM
    M->>A: 叠加无敌 BGM
    M->>A: 淡出普通 BGM
    G->>M: 无敌结束
    M->>A: 恢复普通 BGM
```


### 4.2 音效播放状态机

```mermaid
stateDiagram-v2
    [*] --> Idle
    
    Idle --> Loading: 请求播放
    Loading --> CheckPriority: 加载完成
    
    CheckPriority --> Playing: 优先级足够
    CheckPriority --> Queued: 优先级不足
    CheckPriority --> Dropped: 超过最大数量
    
    Playing --> FadingOut: 播放完成
    Playing --> Interrupted: 被高优先级打断
    
    FadingOut --> Idle: 淡出完成
    Interrupted --> Idle: 立即停止
    Queued --> Playing: 有空闲通道
    Dropped --> Idle: 丢弃音效
    
    Note right of Playing
        音量由优先级决定
        位置影响立体声平衡
    end note
```
