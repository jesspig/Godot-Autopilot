# 一页纸说明：Dodge the Creeps

## 一句话概念

俯视 2D 生存闪避小游戏：玩家在 480×720 竖屏场地里移动，躲避从屏幕边缘不断生成的敌人，活得越久分数越高，被碰到即结束，可一键重开。

## 钩子

- 规则一眼能懂：没有攻击，只有走位。
- 节奏直接：开局 2 秒准备，之后每 0.5 秒一只敌人、每秒 1 分。
- 重开零成本：Game Over 后回到标题 + Start 按钮，再按一次即开局。

## 核心循环

开始（Start 按钮 / `start_game` 动作）→ Get Ready 2 秒 → 敌人生成 + 计分 → 被撞 Game Over → 回标题 → 再开始。

## 范围（现状实录）

- 单一主场景 `main.tscn`，无选关、无存档、无多关卡。
- 玩家 1 个（`player.tscn` + `player.gd`），敌人 1 种场景复用 3 套外观（`mob.tscn` + `mob.gd`）。
- HUD 只有分数、中央消息、Start 按钮（`hud.tscn` + `hud.gd`）。
- 输入 5 个动作：`move_left` / `move_right` / `move_up` / `move_down` / `start_game`（配置见源库 `project.godot` 原件）。
- 竖屏 480×720，`gl_compatibility` 渲染器，背景音乐 + 死亡音效各 1 个。

## 成功标准（作为测试床）

- 在编辑器里打开 `main.tscn` 能认出完整结构（玩家、生成路径、三个 Timer、HUD、两个音频）。
- 按下运行 → Start → 能走位、能刷怪、能记分、被撞后能回标题再开。
- 截图能对上 `screenshots/dodge.png` 的整体观感（竖屏、深色背景、顶部大分数）。

## 非目标

- 不是设计稿：不含新关卡、新敌人、新系统提案。
- 不含网络、存档、内购、移动端适配（手柄事件虽在输入映射里存在，但文档仅实录，不承诺已验证手柄行为——未核实）。
