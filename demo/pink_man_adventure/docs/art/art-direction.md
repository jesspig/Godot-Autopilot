# 美术方向与呈现要求

本文规定画面的**呈现标准**，素材清单见 [asset-catalog.md](./asset-catalog.md)。

## 风格定位

- **像素艺术（Pixel Art）**：素材为 16×16（地形/尖刺）到 96×96（角色特效）的原生像素风格，四角色配色统一、轮廓清晰。
- **高对比可读性**：危险物与可交互物必须一眼可辨；地面与背景的明度/色相要拉开（蓝色系背景 + 暖色系地面/角色的组合已被素材保证）。
- **不做再创作**：不使用 `assets/` 之外的图像素材，不修改原始文件；允许在工程内做必要的复制与引用。

## 缩放与显示

| 要求 | 说明 |
|---|---|
| 整数倍缩放 | 屏幕放大必须是整数倍（如 320×180 视口 ×4 = 1280×720），避免非整数缩放造成像素模糊或抖动 |
| 关闭平滑过滤 | 纹理采样使用最近邻（Nearest），保持像素边缘 |
| 保持宽高比 | 缩放不得拉伸变形；窗口比例变化时用留边或按设计比例适配 |
| 角色对齐 | 角色视觉尺寸 32×32；碰撞体底部与视觉脚底对齐（见 [../gdd/mechanics.md](../gdd/mechanics.md)） |

## 动画使用原则

- 帧数见 [asset-catalog.md](./asset-catalog.md)；播放速度由实现者按手感调整，但**一次性动画**（跳跃/二段跳/墙跳/受击/终点触发）应播放完整后回到循环态。
- 死亡表现目标时长 0.70s（与 7 帧的 Hit 图在常见帧率下吻合，可供参考）。
- 墙滑状态没有专用动画，允许复用下落动画；不额外创造素材。

## 视觉反馈优先级

1. **死亡**：必须先于一切其他反馈被看到；死亡期间玩家不可控。
2. **收集与检查点**：有明确的状态变化（消失 / 旗帜升起等）。
3. **胜利**：终点有显著的触发视觉与提示。
4. **点缀（可选）**：阴影、灰尘粒子、彩带、过渡等可使用 `Other/` 素材，但不得影响判定清晰度。

## 相机与背景

- 背景允许平铺（64×64）覆盖世界；背景不得比前景更亮或更花，避免干扰判定。
- 相机视野限制在世界矩形内，不露出空白区（详见 [../gdd/level-design.md](../gdd/level-design.md)）。

## 美术验收

- [ ] 所有可见素材来自 `assets/`，路径原样引用。
- [ ] 画面无模糊、无拉伸；角色与地形比例与设计一致（截图核对）。
- [ ] 危险物与地面/背景对比清晰，可一眼辨认（截图核对）。
- [ ] 动画切换符合 [../gdd/mechanics.md](../gdd/mechanics.md) 的反馈映射。
- [ ] 可选点缀素材未影响玩法判定与可读性。
