# 美术方向与呈现要求

## 风格

复古极简街机风：深 slate 底（`ColorRect`，见 [../gdd/level-design.md](../gdd/level-design.md)）+ 白色中线 + 青/品红双拍 + 白球。无动画帧、无粒子、无字体定制，全部表现力来自布局与双色区分。

## 呈现规则

- 像素呈现：画布纹理最近邻过滤（源库原件 `textures/canvas_textures/default_texture_filter=0`），窗口整数拉伸（`canvas_items` + `integer`），避免缩放模糊。
- 身份区分：左拍青（`Color(0,1,1,1)`）、右拍品红（`Color(1,0,1,1)`），为唯一的双方区分手段；`You` 标签辅助确认本端球拍。
- 文字：默认字体；胜负标签文案固定 `The Winner!`；状态失败行浅红（`Color(1,0.43,0.35,1)`）。

## 验收要求

- 编辑器视口截图核对：背景铺满、中线居中、双拍染色正确、球拍 `You` 标签存在。
- 运行截图核对：640×400 逻辑尺寸下无拉伸变形（未核实：不同窗口尺寸下的整数缩放表现，需截图确认）。
