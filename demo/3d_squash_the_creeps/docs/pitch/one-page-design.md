# 一页纸设计：Squash the Creeps（3D）

## 一句话概念

第三人称 3D 竞技场动作小游戏：玩家在方形场地里追逐随机生成的小怪，从上方跳跃压扁它们得分，被小怪正面碰到即失败，可按键重试。这是官方"Your first 3D game"教程的完成版（现状实录，非立项提案）。

## 钩子

- 跳跃 + 压扁的一击反馈：压扁得分并弹跳，可连续追击下一只。
- 敌人持续从场地边缘生成并冲向玩家，存活越久压力越大。
- 单一分数目标：尽可能多地压扁，失败即结算 hunts。

## 核心循环

移动追怪 → 跳跃瞄准 → 落到怪顶压扁（+1 分并弹跳）→ 继续追下一只 → 失误被撞（停止生成、显示重试）→ 按确认键重开。

## 操作（现状）

详见 `gdd/mechanics.md`；官方 README 键位表：方向键/WASD/手柄左摇杆移动，空格/鼠标右键/手柄 A（Cross）跳跃，失败后按空格或回车（`ui_accept`）重试。

## 范围（实际有/没有）

- 有：1 个竞技场主场景（`Main.tscn`）、玩家角色（`Player.tscn`）、小怪（`Mob.tscn`）、自动播放音乐（`MusicPlayer.tscn`）、计分 Label、失败重试遮罩、定时生成器、3D 物理碰撞与层。
- 没有：多关卡、主菜单/选关、暂停菜单、存档、道具、多种敌人（只有一种 Mob，速度随机）。

## 成功标准（现状即标准）

- 打开 `Main.tscn` 能看到完整竞技场（地面、边界墙、灯光、相机、生成路径、UI）。
- 运行后小怪每 0.5 秒从边缘生成并冲向玩家；玩家可移动跳跃；压扁得分；被撞显示重试；确认键重开。
- 详见 `test/acceptance.md`。

## 测试床定位

本工程作为 GDA 插件 E2E 测试床，覆盖 3D 场景检查（节点树、变换、相机视角）、物理行为验证（移动/跳跃/挤压/碰撞层）、自动加载与 UI 验证。测试约定见 `test/test-plan.md`。
